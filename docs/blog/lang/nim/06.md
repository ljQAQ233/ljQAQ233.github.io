# 代码块

> block

`block` 指定变量的生命周期, 配合 `break` 跳出多重循环

---

```nim
let a = block calc:
  var x = 1
  x + 1
echo a
echo x # Error: undeclared identifier: 'x'
```

`block` 将最后一个表达式作为返回值, 加上其 **划分作用域** 的功能, 在表述计算的中间过程 尤为实用 (*￣з￣)

---

```nim
outer:
  for i in 1..10:
    for j in 1..10:
      if i * j > 30:
        break outer
```
