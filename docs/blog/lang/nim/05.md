# 类型与推断

nim 支持类型推断

```nim
let a = 5
echo typeof(a) # int
```

```nim
var x = int(7/3.0)
echo typeof(x) # int
```

---

对于一个值可以被多个类型存储时可以考虑显式指定, nim 采用后置类型声明:

```nim
let a = 5
echo typeof(a) # int
let b: float64 = 5
echo typeof(b) # float64
```

---

nim 不能像 rust 一样根据 后续 来推断类型: ヾ(▼ﾍ▼；)

```nim
var y = @[]
y.add("hello")
y.add("world")
echo repr(y)
```

此时需要显式指定:

```nim
var y: seq[string] = @[]
```
